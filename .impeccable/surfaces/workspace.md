# Magic Code Workspace

## Mode

Operate. The user is repeatedly inspecting and changing an artifact while preserving conversational context.

## Direction Contract

### World

BoardUI workbench: bright neutral workspace, semantic surfaces, quiet chrome, crisp separators, compact controls, and one high-visibility targeting accent. No marketing hero, decorative illustration, or card grid.

### First Viewport

The product mechanism is already active: a real conversation sits beside a real editable preview. The preview visibly contains selectable interface elements, a mode toolbar, and a contextual inspector so the user understands “指哪打哪” by doing it.

### Information Hierarchy

1. Artifact preview and the current target.
2. Main conversation and actionable AI state.
3. Contextual modes, annotations, versions, and properties.
4. Project navigation and status.

### Signature Interaction

Target mode turns the pointer into a precise crosshair. Hovering reveals the element boundary and clicking pins an anchored label, synchronizes the inspector, and prepares a structured prompt. Region selection draws a live rectangle and annotation mode drops numbered pins.

### Responsive Behavior

Desktop keeps chat and canvas side by side. Narrow screens switch between Chat and Canvas with a persistent segmented control; contextual drawers become bottom sheets without losing selections or draft text.

### Honest Risk

A dense workspace can feel busy. The implementation must hide mode-specific tools until needed and preserve generous breathing room around the active artifact.
