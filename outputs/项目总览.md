# Magic Code 项目总览

## 一句话介绍

Magic Code 是一款为 AI 对话增加可视化交互能力的助手：用户可以在独立预览页中直接选中、标注或圈定内容，再把明确的视觉上下文交给 AI 处理。

## 项目背景

用 AI 编写代码、设计界面或修改文案时，用户经常需要用文字描述屏幕上的位置和对象。描述不够精确时，AI 容易改错地方。用户在主对话中临时追问，也可能打断原有思路；而生成结果如果只显示在聊天框里，批注、比较和继续修改都不够顺手。

Magic Code 希望把这类沟通从“描述目标位置”转变为“直接指向目标”，并让产物和对话在同一工作流中衔接。

## 目标用户

- 使用 AI 生成或修改网页、界面原型、代码和长文案的个人用户。
- 需要快速反馈局部问题，但不希望打断主对话的设计师、开发者和内容创作者。
- 希望用直观操作表达修改意图、但不熟悉专业设计或代码工具的普通用户。

## 核心价值

1. **定位更准确**：点击页面元素，将元素身份及必要上下文一并交给 AI。
2. **对话不断线**：选中聊天文本后，在独立小窗里追问，保留主会话上下文。
3. **产物可操作**：在侧边预览页查看和标注 AI 生成的结果，而不只是在聊天消息里阅读。

## 核心功能

### 首版核心能力

- **侧边独立展示页**：在聊天旁预览生成的网页、原型或长内容，并支持基础批注。
- **选中文字单独提问**：选中聊天中的文本后开启关联该文本的小对话，不改变主对话状态。
- **坐标系模式**：在预览页点击目标位置，记录对应元素、文本和页面位置，作为 AI 修改请求的上下文。

### 后续扩展方向

- 圈选区域、语音定点指令、常用修改快捷栏。
- 批注一键同步给 AI、多小窗分类管理、历史版本回退和前后对比。
- HTML/文案/图片等内容导出、元素属性提示、多人协作批注。

## 项目亮点

- **指向式上下文**：将点击位置映射到页面元素，而不是只向 AI 发送一个孤立的屏幕坐标。
- **主线与支线分离**：临时问答有自己的小窗，不污染或重置主聊天。
- **沟通与产物同屏**：预览、定位、批注和 AI 修改围绕同一份内容展开。
- **渐进式扩展**：先验证“定位是否比描述有效”，再逐步增加协作、语音和版本等能力。

## 首版成功信号

- 用户能从生成内容进入预览，并完成一次针对具体元素的修改请求。
- AI 能在多数测试场景中正确理解被点击的元素及其邻近上下文。
- 用户能在不改变主对话的情况下，对选中的聊天文本进行追问。
- 用户能把预览页批注发送给 AI，并确认批注对应到正确内容。
